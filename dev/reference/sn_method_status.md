# Deprecated alias of `sn_get_method_status()`

`sn_method_status()` is a deprecated compatibility alias. Use
[`sn_get_method_status()`](https://zerostwo.github.io/shennong/dev/reference/sn_get_method_status.md)
directly; the alias will be removed in a future release.

## Usage

``` r
sn_method_status(...)
```

## Arguments

- ...:

  Named arguments passed on to
  [`sn_get_method_status()`](https://zerostwo.github.io/shennong/dev/reference/sn_get_method_status.md).

## Value

Result of `sn_get_method_status(...)`.
