# Deprecated alias of `sn_run_bulk_deconvolution()`

`sn_deconvolve_bulk()` is a deprecated compatibility alias. Use
[`sn_run_bulk_deconvolution()`](https://zerostwo.github.io/shennong/dev/reference/sn_run_bulk_deconvolution.md)
directly; the alias will be removed in a future release.

## Usage

``` r
sn_deconvolve_bulk(...)
```

## Arguments

- ...:

  Named arguments passed on to
  [`sn_run_bulk_deconvolution()`](https://zerostwo.github.io/shennong/dev/reference/sn_run_bulk_deconvolution.md).

## Value

Result of `sn_run_bulk_deconvolution(...)`.
