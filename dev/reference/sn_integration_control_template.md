# Deprecated alias of `sn_get_integration_control_template()`

`sn_integration_control_template()` is a deprecated compatibility alias.
Use
[`sn_get_integration_control_template()`](https://zerostwo.github.io/shennong/dev/reference/sn_get_integration_control_template.md)
directly; the alias will be removed in a future release.

## Usage

``` r
sn_integration_control_template(...)
```

## Arguments

- ...:

  Named arguments passed on to
  [`sn_get_integration_control_template()`](https://zerostwo.github.io/shennong/dev/reference/sn_get_integration_control_template.md).

## Value

Result of `sn_get_integration_control_template(...)`.
