# Plot spatial-feature statistics

Plot spatial-feature statistics

## Usage

``` r
sn_plot_spatial_svg(x, result_id = NULL, n = 30L, object = NULL)
```

## Arguments

- x:

  A Seurat object or spatial-feature result.

- result_id:

  Stored result result_id.

- n:

  Number of features.

- object:

  Alias for `x`; supply only one of `x` and `object`.

## Value

A `ggplot` object.
