# Run spatial deconvolution through cell2location

`sn_run_spatial_deconvolution()` is a deprecated compatibility alias.
Use
[`sn_run_cell2location()`](https://zerostwo.github.io/shennong/dev/reference/sn_run_scarches.md)
directly.

## Usage

``` r
sn_run_spatial_deconvolution(...)
```

## Arguments

- ...:

  Additional arguments passed to
  [`sn_call_pixi_environment()`](https://zerostwo.github.io/shennong/dev/reference/sn_prepare_pixi_environment.md).
