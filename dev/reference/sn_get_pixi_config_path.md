# Locate a bundled pixi config

Locate a bundled pixi config

## Usage

``` r
sn_get_pixi_config_path(environment = NULL)
```

## Arguments

- environment:

  Python environment name.

## Value

A path to the package-bundled `pixi.toml` template.

## Examples

``` r
sn_get_pixi_config_path("scvi")
```
