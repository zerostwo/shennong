# Deprecated alias of `sn_run_enrichment()`

`sn_enrich()` is a deprecated compatibility alias. Use
[`sn_run_enrichment()`](https://zerostwo.github.io/shennong/dev/reference/sn_run_enrichment.md)
directly; the alias will be removed in a future release.

## Usage

``` r
sn_enrich(...)
```

## Arguments

- ...:

  Named arguments passed on to
  [`sn_run_enrichment()`](https://zerostwo.github.io/shennong/dev/reference/sn_run_enrichment.md).

## Value

Result of `sn_run_enrichment(...)`.
