# Deprecated alias of `sn_get_metabolic_signatures()`

`sn_metabolic_signatures()` is a deprecated compatibility alias. Use
[`sn_get_metabolic_signatures()`](https://zerostwo.github.io/shennong/dev/reference/sn_get_metabolic_signatures.md)
directly; the alias will be removed in a future release.

## Usage

``` r
sn_metabolic_signatures(...)
```

## Arguments

- ...:

  Named arguments passed on to
  [`sn_get_metabolic_signatures()`](https://zerostwo.github.io/shennong/dev/reference/sn_get_metabolic_signatures.md).

## Value

Result of `sn_get_metabolic_signatures(...)`.
