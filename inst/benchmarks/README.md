# Reproducible benchmark snapshots

`single-cell-autozyme-benchmark.json` and its CSV summary are generated by:

```sh
Rscript scripts/real-data/benchmark-single-cell-autozyme.R \
  --root data-local/pkgdown-real \
  --output inst/benchmarks/single-cell-autozyme-benchmark.json \
  --repetitions 3
```

The local Kotliarov PBMC fixture is validated before execution and remains
excluded from Git and the built package. Every baseline and accelerated run is
performed in a fresh R process. The JSON retains raw repetitions, environment
metadata, output-equivalence checks, and patch rollback evidence; the CSV is a
display-oriented median summary.
